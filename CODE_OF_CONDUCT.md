# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good faith, argue with evidence rather than with people, and accept
correction gracefully. Being wrong about a statistic is normal in this field. Update when shown
better evidence.

Report unacceptable behaviour privately through the "Report a vulnerability" button on this
repository's Security tab, which reaches the maintainers only. Reports are handled in confidence.
